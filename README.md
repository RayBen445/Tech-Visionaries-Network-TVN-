# 🚀 Tech Visionaries Network (TVN)

**Africa’s Tech Builders Network**

Tech Visionaries Network (TVN) is a growing ecosystem of developers, innovators, and forward-thinking builders across Africa.

This repository contains the official landing experience used to onboard early members into the network.

---

## 🌍 About TVN

TVN is focused on bringing together individuals who are not just learning tech, but actively building, experimenting, and creating real-world solutions.

It is designed to evolve into a full ecosystem that supports:

- Learning
- Collaboration
- Product development
- Opportunity sharing

---

## 🎯 Current Focus

The current version of TVN is in its early access phase, focused on:

- Building a network of founding members
- Collecting structured user data
- Creating a high-quality community pipeline
- Preparing for platform expansion

---

## ⚙️ System Overview

This landing page functions as a controlled onboarding funnel:

**User → Form → Data Capture → WhatsApp → Community Entry**

---

## 🧠 Core Features

- **Futuristic, animated interface:** Immersive 3D background powered by Three.js.
- **Structured onboarding form:** Seamless data collection with Formspree integration.
- **Country-based segmentation:** Custom dropdown for regional targeting.
- **International phone handling:** Robust validation and formatting with `intl-tel-input`.
- **Controlled WhatsApp flow:** Automated redirection to the community entry point.
- **Conversion-focused UX:** Optimized form validation and premium motion design.
- **Countdown-driven launch:** Real-time urgency system for early access.

---

## 🧩 Tech Stack

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Animations:** motion/react (Framer Motion)
- **3D Graphics:** Three.js
- **Icons:** Lucide React
- **Backend:** Formspree
- **Utilities:** intl-tel-input
